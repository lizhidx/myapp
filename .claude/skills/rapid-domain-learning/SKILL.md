# 快速认知跨越：三步法

核心信念：真正的门槛不是智力，而是**是否有勇气修正自己的认知**。
本 skill 的目标不是替用户给出结论，而是帮用户搭好一个**全面、可校正**的判断框架。

## 开始前

1. 明确用户要研究的**领域/议题**和**要回答的具体问题**（例如"谁会赢得这次选举？"而不只是"美国政治"）。不清楚就问一句。
2. 询问（或从上下文推断）用户**当前的看法和主要信息来源**——这是第一步打破茧房的起点。用户不愿说也可以，直接继续。
3. 如果议题涉及近期事件、实时数据或具体人物的最新观点，优先使用联网搜索核实，并标注信息日期；不确定的内容明确说"不确定"，不要编造人名、头衔、著作或数据。

## 第一步：警惕信息茧房

- **目的**：防止观点偏激和狭隘，确保对局势有全面客观的认知。
- **核心**：打破单一信息渠道，强迫接触多元、甚至对立的观点。

执行：
1. 列出该议题上的**主要阵营/立场**（通常 3–5 个，包括用户可能不认同的那一方），对每一方：
   - 用其支持者会认可的方式，**最强版本**地陈述其核心论点（steelman，而非稻草人）；
   - 其依据的关键证据或数据；
   - 其最常被批评的弱点。
2. 指出用户现有信息源可能存在的**盲区**（如果已知其来源）。
3. 推荐**各立场的代表性信息渠道**（媒体、智库、播客、Newsletter、数据网站），并标注其倾向。
4. 给出一个"反茧房自检"问题：*"有哪一个事实，如果成立，会让我改变看法？"*

## 第二步：寻找完整的专家光谱

- **目的**：快速构建领域内的认知框架，站在巨人的肩膀上高效学习。
- **核心**：构建一套全方位的知识来源矩阵。

执行：
1. 推荐该领域内**不同立场、观点相对客观且具代表性**的顶尖学者和专业人士，覆盖：
   - 不同政治/学术立场；
   - 不同身份类型（学者、一线从业者、数据分析师/量化派、记者、前官员等）；
   - 尽量包含不同地区/文化视角。
2. 以表格输出矩阵：

   | 人物/机构 | 身份 | 立场/学派 | 核心观点 | 代表作品/渠道 | 历史表现或可信度备注 |
   |---|---|---|---|---|---|

3. 指出专家之间**真正的分歧点**在哪里（是事实判断不同、模型假设不同，还是价值取向不同）。
4. 建议学习顺序：先读哪位建立框架，再读哪位形成对照。
5. 提醒用户：先广泛吸收，再据此梳理**自己的判断逻辑**，而不是直接选边站。

## 第三步：搞清楚基本概念

- **目的**：建立专业知识根基，杜绝"不懂装懂"，确保数据分析的准确性。
- **核心**：彻底拆解和掌握专业术语及基础逻辑。

执行：
1. 列出理解该议题**必须掌握的 5–10 个核心概念**（例如选举分析中的：误差范围、加权、可能投票者模型、提前投票、民调机构评级/house effect、系统性偏差等）。
2. 对每个概念给出：
   - 一句话定义；
   - 背后的原理（为什么是这样）；
   - **适用边界与常见误用**（什么时候它会失灵、常被如何误读）；
   - 一个具体例子。
3. 邀请用户对任何不熟悉的术语继续追问，坚持"查根问底，直到真正理解"。可以出 2–3 道小题检验理解。

## 综合：形成并校正自己的判断

在三步之后，帮助用户把学到的东西与**数据分析**（如提前投票数据、民调机构历史表现、关键指标）和**直觉**结合：

1. 梳理一个判断框架：关键变量有哪些？各自权重如何？目前数据指向哪里？
2. 让用户写下**当前判断 + 置信度**（如"60% 认为 A"）。
3. 列出**会让判断改变的信号**（"如果出现 X，我会下调到 40%"）。
4. 鼓励定期回顾：新信息出现时更新判断，并记录自己哪里错了、为什么错——这正是"修正认知的勇气"。

## 输出原则

- 用用户使用的语言回复（默认中文）。
- 各立场篇幅与语气尽量对等，不暗示哪方"正确"；用户要求时可以给出你的评估，但要说明依据和不确定性。
- 区分**事实**、**主流解读**和**你的推断**。
- 用户只要求其中某一步时，只做那一步，不必全流程走完。
